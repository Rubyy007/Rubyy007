## 🔬 Current Projects

### 🗄️ RubixDB

A **Rust-based database engine** exploring multiple storage engines including **Log, LSM, and B+Tree**, along with a dedicated **Write/Ingestion Engine and Read Engine**.

The long-term goal is to build an engine that can evaluate workload characteristics and select an appropriate storage strategy at the **partition level**.

### 🗜️ RubixZip

An open-source **high-performance compression and extraction system written in Rust**, focused on efficient I/O, parallel compression/decompression, chunk-based processing, and a native archive format.

### 📊 Data Engineering Platform

Building practical pipelines using **Apache Spark, PySpark, Kafka, Airflow, Databricks, Snowflake, and Python** for large-scale data ingestion and processing.
